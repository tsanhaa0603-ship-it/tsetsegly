# tools/

Маркетингийн туслах скриптүүд. Апп-тай холбоогүй, build-д ордоггүй.

## prerender-seo.mjs

`npm run build`-ийн дараа автоматаар ажилладаг. Гараар ажиллуулах шаардлагагүй.

**Ямар асуудлыг шийддэг вэ.** React SPA учир бүх маршрут `index.html`-ийн ижил
`<title>`, `description`-ыг хуваалцдаг. Google-ийн хувьд энэ нь «5 хуудас, 1 гарчиг»
— индексжүүлэхэд шууд саад. Энэ скрипт маршрут бүрд өөрийн meta-тай статик HTML
үүсгэнэ (`dist/ready/index.html` гэх мэт). Vercel файлын системийг rewrite-аас
түрүүлж шалгадаг тул `/ready` хүсэлт тэр файл руу очиж, React дараа нь ердийнхөөр
hydrate хийнэ.

Мөн үүсгэдэг:

- **Бэлэн баглаа бүрийн хуудас.** Build үед `GET /api/ready`-ээс татаж
  `dist/ready/<slug>/index.html` үүсгэнэ — нэр, үнэ бүхий гарчиг, өөрийн зураг нь
  og:image, дээр нь **`Product` схем** (үнэ, MNT, InStock). Урт сүүлтэй хайлтын
  гол эх үүсвэр. API унтарсан эсвэл баглаа slug-гүй бол алгасна, build унахгүй.
- **JSON-LD `Florist` схем** бүх хуудсанд — утас, ажлын цаг, 6 дүүргийн `areaServed`,
  сошиал холбоос. Гудамжны хаяггүй, учир нь салбар дэлгүүргүй.
- **`sitemap.xml`** — статик маршрут + баглаа бүр, `lastmod`-той.
  `public/sitemap.xml` устгасан — хоёр эх сурвалж зөрөхөөс сэргийлж энэ скрипт л эзэмшинэ.

Скрипт **idempotent** — dist дээр хэдэн ч удаа ажиллуулсан таг давхарлахгүй
(суусан тагуудыг эхлээд цэвэрлэдэг).

### Маршрутын meta засах

`ROUTES` массивыг засна. `title` 60 тэмдэгт, `description` 150–160 тэмдэгт орчим
байвал Google хайлтын үр дүнд тасрахгүй.

Утас, ажлын цаг, дүүрэг өөрчлөгдвөл `BIZ` объектыг зас — Google Business Profile
болон `/contact` хуудастай **яг таарч байх ёстой**.

### Заавал биш орчны хувьсагчид

Vercel → Project Settings → Environment Variables хэсэгт нэмнэ. Тохируулаагүй бол
тухайн таг огт нэмэгдэхгүй (хоосон утга үлдэхгүй).

| Хувьсагч | Юу хийдэг |
|---|---|
| `GSC_VERIFICATION` | Search Console-ийн `google-site-verification` meta таг |
| `GA4_ID` | Google Analytics 4 (`G-XXXXXXXXXX`) gtag суулгац |

## check-influencers.mjs

Instagram-ийн нээлттэй профайлын өгөгдлөөс нэр дэвшигчдийн **жинхэнэ дагагчийн тоо**,
постын тоо, **идэвхжлийн хувийг** бөөнөөр татаж, Tsetsegly-ийн шалгуураар шүүнэ.

```bash
node tools/check-influencers.mjs handles.txt
node tools/check-influencers.mjs undrrly cherrymuunuu munhluu
```

`handles.txt` — мөр бүрд нэг хаяг. `@` тэмдэг, бүтэн URL аль нь ч болно.

### Гаралт

Терминал дээр шүүлтийн хүснэгт, мөн `influencers.csv` файл. CSV дотор
`UB_audience_%`, `contacted`, `replied`, `posted`, `promo_code`, `orders`
гэсэн хоосон багана байгаа — эдгээрийг гараар бөглөж хяналтын хүснэгт болгоно.

### Шалгуур

| Үзүүлэлт | Хязгаар | Яагаад |
|---|---|---|
| Дагагч | 3,000 – 80,000 | Доош нь хүрээ бага, дээш нь бартер хүлээж авахгүй |
| Идэвхжил | 2%-иас дээш | Доош бол дагагч идэвхгүй эсвэл худалдаж авсан |
| Данс | нээлттэй байх | Хаалттай данс сурталчилгаанд тохирохгүй |

Хязгаарыг файлын дээд талын тогтмолуудаас өөрчилнө.

### HTTP 401 гарвал

Instagram нэрээ нууцлан хандахыг хааж эхэлдэг. Тэр үед өөрийн session-оор ханд:

```powershell
$env:IG_SESSIONID = "<sessionid>"
node tools/check-influencers.mjs handles.txt
```

Утгыг Chrome → instagram.com → F12 → Application → Cookies → `sessionid`-аас хуулна.

Энэ бол таны нэвтрэлтийн түлхүүр. **Файлд бүү хадгал, git-д бүү оруул** — зөвхөн
терминалын хувьсагчаар өг. Хэсэг хугацааны дараа хүчингүй болно, дахин хуулна.

### Анхаарах

- **Үзэгчийн байршлыг энэ скрипт хэмжиж чадахгүй.** Энэ нь хамгийн чухал шалгуур
  боловч зөвхөн тухайн хүн Insights → Audience → Top locations хэсгээсээ өгч чадна.
  Улаанбаатар 70%-иас доош бол хас — бид зөвхөн УБ-д хүргэдэг.
- Идэвхжил **20%-иас дээш** гарвал түүврт вирус болсон пост орсон гэсэн үг.
  Алдаа биш, харин «Reels нь дагагчаасаа хол давж хүрдэг» гэсэн дохио — гараар шалга.
- Хүсэлт хооронд 1.2 секунд хүлээдэг. Өдөрт **50–100 дансаас илүүг бүү шалга**,
  Instagram түр хаадаг.
