## Стикерийн бодит хэмжээ

Стикерийн PDF дэх зураг бүр **1:1 бодит хэмжээтэй** — шууд хэмжиж болно.
Тасархай алтан шугам = зүсэх (die-cut) шугам.

| # | Стикер | Хэмжээ | Хэлбэр |
|---|---|---|---|
| 1 | Лого лацан | Ø 48 мм | Дугуй |
| 2 | Лого лейбл + QR | 80 × 32 мм | Дугуй булантай тэгш өнцөгт |
| 3 | Талархал + арчилгаа | Ø 60 мм | Дугуй |
| 4 | Бэлгийн бичиг | 90 × 40 мм | Дугуй булантай тэгш өнцөгт |
| 5 | Том wordmark | 90 × 55 мм | Дугуй булантай тэгш өнцөгт · тунгалаг винил |

## Захиалахын өмнө үйлдвэртэй тохирох зүйл

Эдгээр PDF нь **загвар батлах, хэмжээ тохирох** зориулалттай. Бодит хэвлэлд орохын
өмнө үйлдвэр дараахыг нэмж бэлтгэнэ:

- **3 мм bleed** — зүсэх шугамын гадна тал руу дэвсгэр өнгийг сунгана.
- **CMYK хөрвүүлэлт** — эдгээр файл RGB. Брэндийн ногоон `#17392B`, алт `#C9A961`-ийг
  үйлдвэрийн ICC профайлаар хөрвүүлж, өнгөний сорьц (proof) авах.
- **Алтан фойл** (цүнхний B хувилбар) — Pantone 871 C, тусдаа spot давхарга болгоно.
- **Фонт** — эцсийн файлд үсгийг муруй (outline) болгоно.
- Цүнхний PDF дэх dieline нь **схем** — 1:1 биш. Үйлдвэр өөрийн хэвийн зураг гаргана.

Бүх фонт PDF дотор шигтгэгдсэн (embedded), тул өөр компьютер дээр нээхэд өөрчлөгдөхгүй.

## Дахин үүсгэх

Загварын эх файл: `public/bag-design.html`, `public/stickers.html`.
Засвар оруулсны дараа:

```bash
npm run print:pdf     # → print/*.pdf
```

Шаардлага: [Playwright](https://playwright.dev) болон Chromium (`npx playwright install chromium`).

Фонтууд `public/fonts/` дотор төсөлтэй хамт хадгалагдсан — PDF нь сүлжээнээс хамаарахгүй.
Фонт шинэчлэх шаардлага гарвал `npm run fonts`.
