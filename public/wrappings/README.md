# Боолтын цаасны зургууд

Дэлгүүрийн бодит боолтын материалын зургууд (25 төрөл).
Эх зураг: `tsetsegly flower shop/matreal/` (HEIC) → вэбэд тохируулан 800px өргөнтэй JPG болгосон.
