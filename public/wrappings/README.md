# Боолтын цаасны зургууд

Энэ хавтаст боолтын цаасны зургийг хийнэ.

## Файлын нэрс (яг эдгээр нэрээр хадгална)

| Файл | Боолт | Үнэ |
|------|-------|-----|
| `cream.png` | Крем цагаан | ₮5,000 |
| `pink.png` | Ягаан хөрс | ₮5,000 |
| `black.png` | Хар тансаг | ₮8,000 |
| `green.png` | Ногоон байгаль | ₮6,000 |

## Зөвлөмж

- **Формат:** `.png` эсвэл `.jpg`
- **Хэмжээ:** 600×400px орчим (хэвтээ), 500KB-аас бага
- Цаасны **бүтэц, өнгө** тод харагдахаар ойроос авсан зураг тохиромжтой
- Файлын нэрийг **жижиг үсгээр**, яг дээрх байдлаар нэрлэнэ

## Ажиллах зарчим

Зураг хийвэл баглаа бүтээх хуудасны "Боолтын цаас" хэсэгт **шууд харагдана** —
код өөрчлөх шаардлагагүй.

Зураг байхгүй бол өнгөт судал (одоогийн загвар) автоматаар харагдана,
тиймээс зургийг нэг нэгээр нь нэмж болно.
